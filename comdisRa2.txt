โจทย์ข้อที่ 06: การจัดการ LVM (Volume Group & Logical Volume)
สร้าง Logical Volume ชื่อ lv1 ให้มีขนาดเท่ากับ 10 LEs ภายใน Volume Group ชื่อ vg1 (สร้าง vg1
โดยกำหนดขนาด PE เป็น 8MB บนพาร์ทิชันของดิสก์ขนาด 400MB) จัดรูปแบบ Logical Volume
ด้วยระบบไฟล์ชนิด XFS และ Mount ไปยัง /mnt/lvfs1 จากนั้นสร้างไฟล์ชื่อ lv1file1 ไว้ในจุด Mount
ดังกล่าว ตั้งค่าให้ระบบไฟล์ Mount โดยอัตโนมัติทุกครั้งที่รีบูตระบบ
คำสั่ง / Solution CLI:
printf "n\np\n1\n\n+400M\nt\n8e\nw\n" | sudo fdisk /dev/nvme0n2
sudo partprobe /dev/nvme0n2
sudo pvcreate /dev/nvme0n2p1
sudo vgcreate -s 8M vg1 /dev/nvme0n2p1
sudo lvcreate -l 10 -n lv1 vg1
sudo mkfs.xfs /dev/vg1/lv1 หรือ sudo mkfs.ext4 /dev/vg1/lv1
sudo mkdir -p /mnt/lvfs1
echo "/dev/vg1/lv1 /mnt/lvfs1 xfs defaults 0 0" | sudo tee -a /etc/fstab
sudo mount -a
sudo touch /mnt/lvfs1/lv1file1
ตรวจสอบ
1. เช็กสถานะ Volume Group และขนาด PE/LE
sudo vgdisplay vg1
2. เช็กสถานะ Logical Volume
sudo lvdisplay /dev/vg1/lv1

สร้างกลุ่มชื่อ group20 และเปลี่ยนการเป็นเจ้าของกลุ่ม (Group Membership) ของ /mnt/lvfs1 ให้เป็น
group20 กำหนดสิทธิ์ Read/Write/Execute บน /mnt/lvfs1 ให้กับเจ้าของ (Owner), สมาชิกในกลุ่ม

โจทย์ข้อที่ 09: การสร้าง Swap Partition ด้วย UUID

โจทย์ข้อที่ 10: การสร้าง Ext4 Partition พร้อม Label
สร้าง Disk Partition ขนาด 100MB บนดิสก์ขนาด 400MB และจัดรูปแบบด้วยระบบไฟล์ชนิด Ext4 กำหนด
Label ชื่อ stdlabel ให้กับระบบไฟล์ Mount ระบบไฟล์แบบถาวรไปยัง /mnt/stdfs1 โดยอ้างอิงจาก
Label ดังกล่าว แล้วสร้างไฟล์ stdfile1 ไว้ในจุด Mount
คำสั่ง / Solution CLI:
printf "n\np\n3\n\n+100M\nw\n" | sudo fdisk /dev/nvme0n2
sudo partprobe /dev/nvme0n2
sudo mkfs.ext4 -L stdlabel /dev/nvme0n2p3
sudo mkdir -p /mnt/stdfs1
echo "LABEL=stdlabel /mnt/stdfs1 ext4 defaults 0 0" | sudo tee -a /etc/fstab
sudo mount -a
sudo touch /mnt/stdfs1/stdfile1
ตรวจสอบ
1. เช็ก Label ของ Partition
sudo e2label /dev/nvme0n2p3
2. เช็กจุด Mount และขนาดพื้นที่
df -h /mnt/stdfs1
3. เช็กไฟล์ทดสอบ
ls -l /mnt/stdfs1

systemctl --user enable --now c80.service
touch /data01/testfile_from_host

Task 08: การจัดการ LVM และ VDO Volume [VM1 — alpha]

sudo mount -a
การตรวจสอบ: ตรวจสอบพื้นที่ดิสก์และการ mount ด้วย df -hT /mnt/vdo1
